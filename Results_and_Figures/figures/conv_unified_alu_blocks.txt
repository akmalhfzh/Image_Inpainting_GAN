=============================================================================
CONV_UNIFIED - ALU LEVEL BLOCK DIAGRAMS (Node + Wire Format)
=============================================================================
Format:
  NODE = hardware component (Adder, Multiplier, Register, MUX, dll)
  WIRE = koneksi antar node. Format: SOURCE --(nama_sinyal[lebar])--> DESTINATION
  [EXT] = sinyal dari luar conv_unified
  Semua nama sinyal diambil langsung dari RTL source code.


=============================================================================
DIAGRAM 1: MAC ARRAY (mac_array.v)
=============================================================================
Arsitektur: 16x Parallel Dot-Product + Binary Adder Tree, 2-Stage Pipeline
Latency: 2 clock cycles (in_valid → out_valid)
Catatan: Stage 0 direplikasi 16x paralel (m = 0..15)

--- NODES ---
NODE  WEIGHT_CACHE        : [EXT] BRAM inside conv_unified. 16 banks.
NODE  IFMAP_TILE           : [EXT] 16x registers inside conv_unified.
NODE  ADDR_GEN             : [EXT] Combinational address calculator.
NODE  AXI4_MASTER_FSM      : [EXT] FSM inside conv_unified.
NODE  VEC_FLATTEN_W        : Generate loop. Packs weight_tile[0:15] → flat vector.
NODE  VEC_FLATTEN_I        : Generate loop. Packs ifmap_tile[0:15] → flat vector.
NODE  ZERO_PAD_MUX[m]      : MUX 2:1. Pilih ifmap atau 0 berdasarkan valid.
NODE  MULTIPLIER[m]        : Signed Multiplier 16b × 16b = 32b.
NODE  SIGN_EXTEND[m]       : Wire routing. 32b → 48b sign extension.
NODE  PIPELINE_REG_1[m]    : D-FlipFlop. 48-bit. Breaks DSP→adder critical path.
NODE  ADDER_L1[0..7]       : 48-bit Signed Adder. Level 1 (8 buah).
NODE  ADDER_L2[0..3]       : 48-bit Signed Adder. Level 2 (4 buah).
NODE  ADDER_L3[0..1]       : 48-bit Signed Adder. Level 3 (2 buah).
NODE  ADDER_L4             : 48-bit Signed Adder. Level 4 FINAL (1 buah).
NODE  PIPELINE_REG_2       : D-FlipFlop. 48-bit. Output register.
NODE  VALID_SHIFT_REG      : 2-bit Shift Register. Delays in_valid by 2 cycles.

--- WIRES (Stage 0: Multiply, ×16 paralel) ---
WEIGHT_CACHE --(weight_tile[m][15:0])--> VEC_FLATTEN_W
VEC_FLATTEN_W --(weight_vec[m*16 +: 16])--> MULTIPLIER[m]              input A

IFMAP_TILE --(ifmap_tile[m][15:0])--> VEC_FLATTEN_I
VEC_FLATTEN_I --(ifmap_vec[m*16 +: 16])--> ZERO_PAD_MUX[m]            input 1 (data)
Constant 16'd0 --(zero)--> ZERO_PAD_MUX[m]                            input 0 (zero)
ADDR_GEN --(valid_vec_w[m])--> ZERO_PAD_MUX[m]                        select
ZERO_PAD_MUX[m] --(ival[15:0])--> MULTIPLIER[m]                       input B

MULTIPLIER[m] --(prod[m][31:0])--> SIGN_EXTEND[m]
SIGN_EXTEND[m] --(prod_sx[m][47:0])--> PIPELINE_REG_1[m]

--- WIRES (Stage 1: Adder Tree, combinational) ---
PIPELINE_REG_1[0] --(prod_reg[0])--> ADDER_L1[0]                      input A
PIPELINE_REG_1[1] --(prod_reg[1])--> ADDER_L1[0]                      input B
PIPELINE_REG_1[2] --(prod_reg[2])--> ADDER_L1[1]                      input A
PIPELINE_REG_1[3] --(prod_reg[3])--> ADDER_L1[1]                      input B
PIPELINE_REG_1[4] --(prod_reg[4])--> ADDER_L1[2]                      input A
PIPELINE_REG_1[5] --(prod_reg[5])--> ADDER_L1[2]                      input B
PIPELINE_REG_1[6] --(prod_reg[6])--> ADDER_L1[3]                      input A
PIPELINE_REG_1[7] --(prod_reg[7])--> ADDER_L1[3]                      input B
PIPELINE_REG_1[8] --(prod_reg[8])--> ADDER_L1[4]                      input A
PIPELINE_REG_1[9] --(prod_reg[9])--> ADDER_L1[4]                      input B
PIPELINE_REG_1[10] --(prod_reg[10])--> ADDER_L1[5]                    input A
PIPELINE_REG_1[11] --(prod_reg[11])--> ADDER_L1[5]                    input B
PIPELINE_REG_1[12] --(prod_reg[12])--> ADDER_L1[6]                    input A
PIPELINE_REG_1[13] --(prod_reg[13])--> ADDER_L1[6]                    input B
PIPELINE_REG_1[14] --(prod_reg[14])--> ADDER_L1[7]                    input A
PIPELINE_REG_1[15] --(prod_reg[15])--> ADDER_L1[7]                    input B

ADDER_L1[0] --(sum_left)--> ADDER_L2[0]                               input A
ADDER_L1[1] --(sum_right)--> ADDER_L2[0]                              input B
ADDER_L1[2] --(sum_left)--> ADDER_L2[1]                               input A
ADDER_L1[3] --(sum_right)--> ADDER_L2[1]                              input B
ADDER_L1[4] --(sum_left)--> ADDER_L2[2]                               input A
ADDER_L1[5] --(sum_right)--> ADDER_L2[2]                              input B
ADDER_L1[6] --(sum_left)--> ADDER_L2[3]                               input A
ADDER_L1[7] --(sum_right)--> ADDER_L2[3]                              input B

ADDER_L2[0] --(sum_left)--> ADDER_L3[0]                               input A
ADDER_L2[1] --(sum_right)--> ADDER_L3[0]                              input B
ADDER_L2[2] --(sum_left)--> ADDER_L3[1]                               input A
ADDER_L2[3] --(sum_right)--> ADDER_L3[1]                              input B

ADDER_L3[0] --(sum_left)--> ADDER_L4                                  input A
ADDER_L3[1] --(sum_right)--> ADDER_L4                                 input B

--- WIRES (Stage 2: Output Register) ---
ADDER_L4 --(tree_out[47:0])--> PIPELINE_REG_2
PIPELINE_REG_2 --(sum_out = row_sum[47:0])--> [OUTPUT ke ACCUMULATOR]

AXI4_MASTER_FSM --(mac_in_valid)--> VALID_SHIFT_REG
VALID_SHIFT_REG --(out_valid = mac_out_valid)--> [OUTPUT ke ACCUMULATOR]

--- RINGKASAN HARDWARE ---
Total Multiplier  : 16 buah (16b × 16b signed)
Total Adder       : 15 buah (48-bit signed), tersusun tree 8+4+2+1
Total MUX 2:1     : 16 buah (zero-pad)
Total D-FlipFlop  : 16 + 1 + 2 = 19 (prod_reg + sum_out_reg + valid_sr)


=============================================================================
DIAGRAM 2: ADDRESS GENERATOR (addr_gen.v)
=============================================================================
Arsitektur: Fully combinational, 16x paralel per tap
Mode: cfg_mode=0 → Conv2D, cfg_mode=1 → ConvTranspose2D
Diagram di bawah menunjukkan path Conv2D (cfg_mode=0)

--- NODES ---
NODE  CONFIG_LUT       : [EXT] Dari generator_top. Layer parameters.
NODE  AXI4_MASTER_FSM  : [EXT] Dari conv_unified. Position counters.
NODE  MUL_HW_IN        : Multiplier. cfg_h_in × cfg_w_in = hw_in.
NODE  MUL_KK           : Multiplier. cfg_k × cfg_k = kk.
NODE  MUL_CIN_KK       : Multiplier. cfg_c_in × kk = cin_x_kk.
NODE  MUL_STRIDE_COUT  : Multiplier. c_out × cin_x_kk = stride_cout.
NODE  MUL_STEP_CIN     : Multiplier. c_in × kk = step_cin.
NODE  DIV_T            : Integer divide/modulo. dy = t/cfg_k, dx = t%cfg_k.
NODE  MUL_Y            : Multiplier. h_out × cfg_stride.
NODE  SUB_Y            : Subtractor. result − cfg_pad.
NODE  ADD_Y            : Adder. result + dy = in_y.
NODE  MUL_X            : Multiplier. w_out × cfg_stride.
NODE  SUB_X            : Subtractor. result − cfg_pad.
NODE  ADD_X            : Adder. result + dx = in_x.
NODE  CMP_Y_GE0        : Comparator. in_y >= 0.
NODE  CMP_Y_LT_HIN     : Comparator. in_y < cfg_h_in.
NODE  CMP_X_GE0        : Comparator. in_x >= 0.
NODE  CMP_X_LT_WIN     : Comparator. in_x < cfg_w_in.
NODE  AND_Y            : AND gate. is_y_valid.
NODE  AND_X            : AND gate. is_x_valid.
NODE  AND_FINAL        : AND gate. valid_vec[t].
NODE  MUL_CIN_HW       : Multiplier. c_in × hw_in.
NODE  MUL_INY_WIN      : Multiplier. in_y × cfg_w_in.
NODE  ADD_IF_ROW       : Adder. (in_y*w_in) + in_x.
NODE  ADD_IF_FINAL     : Adder. c_in*hw_in + row_offset = ifmap_addrs[t].
NODE  ADD_W1           : Adder. cfg_weight_base + stride_cout.
NODE  ADD_W2           : Adder. result + step_cin.
NODE  ADD_W3           : Adder. result + t = weight_addrs[t].

--- WIRES (Pre-compute, shared across all 16 taps) ---
CONFIG_LUT --(cfg_h_in[9:0])--> MUL_HW_IN                             input A
CONFIG_LUT --(cfg_w_in[9:0])--> MUL_HW_IN                             input B
MUL_HW_IN --(hw_in[17:0])--> MUL_CIN_HW

CONFIG_LUT --(cfg_k[3:0])--> MUL_KK                                   input A
CONFIG_LUT --(cfg_k[3:0])--> MUL_KK                                   input B
MUL_KK --(kk[7:0])--> MUL_CIN_KK
CONFIG_LUT --(cfg_c_in[11:0])--> MUL_CIN_KK                           input A
MUL_CIN_KK --(cin_x_kk[25:0])--> MUL_STRIDE_COUT

AXI4_MASTER_FSM --(c_out[11:0])--> MUL_STRIDE_COUT                    input A
MUL_STRIDE_COUT --(stride_cout[25:0])--> ADD_W1

AXI4_MASTER_FSM --(c_in[11:0])--> MUL_STEP_CIN                       input A
MUL_KK --(kk[7:0])--> MUL_STEP_CIN                                   input B
MUL_STEP_CIN --(step_cin[25:0])--> ADD_W2

--- WIRES (Per-tap coordinate, ×16 paralel, Conv2D mode) ---
AXI4_MASTER_FSM --(h_out[9:0])--> MUL_Y                               input A
CONFIG_LUT --(cfg_stride[3:0])--> MUL_Y                                input B
MUL_Y --(h_out*stride)--> SUB_Y                                       input A
CONFIG_LUT --(cfg_pad[3:0])--> SUB_Y                                  input B (subtrahend)
SUB_Y --(base_y_pad)--> ADD_Y                                         input A
DIV_T --(dy)--> ADD_Y                                                 input B
ADD_Y --(in_y)--> CMP_Y_GE0
ADD_Y --(in_y)--> CMP_Y_LT_HIN
ADD_Y --(in_y)--> MUL_INY_WIN

AXI4_MASTER_FSM --(w_out[9:0])--> MUL_X                               input A
CONFIG_LUT --(cfg_stride[3:0])--> MUL_X                                input B
MUL_X --(w_out*stride)--> SUB_X                                       input A
CONFIG_LUT --(cfg_pad[3:0])--> SUB_X                                  input B (subtrahend)
SUB_X --(base_x_pad)--> ADD_X                                         input A
DIV_T --(dx)--> ADD_X                                                 input B
ADD_X --(in_x)--> CMP_X_GE0
ADD_X --(in_x)--> CMP_X_LT_WIN
ADD_X --(in_x)--> ADD_IF_ROW

--- WIRES (Boundary check) ---
Constant 0 --> CMP_Y_GE0                                              input B
CONFIG_LUT --(cfg_h_in)--> CMP_Y_LT_HIN                               input B
Constant 0 --> CMP_X_GE0                                              input B
CONFIG_LUT --(cfg_w_in)--> CMP_X_LT_WIN                               input B

CMP_Y_GE0 --(y_ge0)--> AND_Y                                         input A
CMP_Y_LT_HIN --(y_lt_hin)--> AND_Y                                   input B
CMP_X_GE0 --(x_ge0)--> AND_X                                         input A
CMP_X_LT_WIN --(x_lt_win)--> AND_X                                   input B
AND_Y --(is_y_valid)--> AND_FINAL                                     input A
AND_X --(is_x_valid)--> AND_FINAL                                     input B
AND_FINAL --(valid_vec[t])--> [OUTPUT ke MAC_ARRAY + PIPE_REG]

--- WIRES (ifmap address calculation) ---
AXI4_MASTER_FSM --(c_in[11:0])--> MUL_CIN_HW                         input A
MUL_HW_IN --(hw_in)--> MUL_CIN_HW                                    input B
ADD_Y --(in_y)--> MUL_INY_WIN                                         input A
CONFIG_LUT --(cfg_w_in)--> MUL_INY_WIN                                input B
MUL_INY_WIN --(in_y*w_in)--> ADD_IF_ROW                               input A
ADD_X --(in_x)--> ADD_IF_ROW                                          input B
MUL_CIN_HW --(c_in*hw_in)--> ADD_IF_FINAL                            input A
ADD_IF_ROW --(row_offset)--> ADD_IF_FINAL                             input B
ADD_IF_FINAL --(ifmap_addrs[t][17:0])--> [OUTPUT ke PIPE_REG → DDR]

--- WIRES (weight address calculation) ---
CONFIG_LUT --(cfg_weight_base[25:0])--> ADD_W1                         input A
MUL_STRIDE_COUT --(stride_cout)--> ADD_W1                             input B
ADD_W1 --(base+stride_cout)--> ADD_W2                                 input A
MUL_STEP_CIN --(step_cin)--> ADD_W2                                   input B
ADD_W2 --(result)--> ADD_W3                                           input A
Constant t[25:0] --> ADD_W3                                            input B
ADD_W3 --(weight_addrs[t][25:0])--> [OUTPUT ke PIPE_REG → DDR]

--- RINGKASAN HARDWARE ---
Total Multiplier  : 5 (shared) + 3 (per-tap) = 5 + 3×16 = 53
Total Adder       : 3 per-tap + 3 weight = 3×16 + 3 = 51
Total Subtractor  : 2 per-tap = 2×16 = 32
Total Comparator  : 4 per-tap = 4×16 = 64
Total AND gate    : 3 per-tap = 3×16 = 48
Note: Synthesis mengoptimasi banyak dari ini jadi LUT karena combinational


=============================================================================
DIAGRAM 3: ACCUMULATOR + REQUANTIZATION (inside conv_unified.v)
=============================================================================
Arsitektur: 48-bit accumulator + fixed-point requantization + saturation
Accumulator loop: per c_in channel. Requant: combinational dari acc_reg.

--- NODES ---
NODE  BIAS_MEM          : [EXT] BRAM dari generator_top. Q8.8 signed.
NODE  MAC_ARRAY         : [EXT] Output dari mac_array. row_sum + mac_out_valid.
NODE  AXI4_MASTER_FSM   : [EXT] Control: is_first = (c_in_cnt == 0).
NODE  BIAS_SIGN_EXT     : Wire routing. 16b → 48b sign extension.
NODE  BIAS_LEFT_SHIFT   : Left Shift. <<< FRAC_W (=8). Aligns bias to Q16.8 in 48b.
NODE  MUX_BIAS_ACC      : MUX 2:1. is_first ? bias_extended : acc_reg.
NODE  ADDER_ACC         : 48-bit Signed Adder. acc_next = mux_out + row_sum.
NODE  ACC_REG           : D-FlipFlop. 48-bit. acc_reg. Latched on mac_out_valid.
NODE  ADDER_ROUND       : 48-bit Signed Adder. acc_reg + 0.5_ULP.
NODE  ARITH_RSHIFT      : Arithmetic Right Shift. acc_rounded >>> 8 (FRAC_W).
NODE  CMP_SAT_POS       : Comparator. acc_shifted > +32767.
NODE  CMP_SAT_NEG       : Comparator. acc_shifted < -32768.
NODE  MUX_SAT_NEG       : MUX 2:1. sat_neg ? -32768 : acc_shifted[15:0].
NODE  MUX_SAT_POS       : MUX 2:1. sat_pos ? +32767 : mux_neg_out.

--- WIRES (Bias Extension) ---
BIAS_MEM --(bias_val[15:0])--> BIAS_SIGN_EXT                          input
BIAS_SIGN_EXT --(48b sign-extended)--> BIAS_LEFT_SHIFT                 input
BIAS_LEFT_SHIFT --(bias_extended[47:0])--> MUX_BIAS_ACC                input 1

--- WIRES (Accumulation Loop) ---
ACC_REG --(acc_reg[47:0])--> MUX_BIAS_ACC                             input 0 (feedback)
AXI4_MASTER_FSM --(is_first)--> MUX_BIAS_ACC                          select
MUX_BIAS_ACC --(mux_out[47:0])--> ADDER_ACC                           input A
MAC_ARRAY --(row_sum[47:0])--> ADDER_ACC                              input B
ADDER_ACC --(acc_next[47:0])--> ACC_REG                                data input
MAC_ARRAY --(mac_out_valid)--> ACC_REG                                 clock enable

--- WIRES (Rounding) ---
ACC_REG --(acc_reg[47:0])--> ADDER_ROUND                              input A
Constant 128 (= 1<<7 = 0.5 ULP) --> ADDER_ROUND                       input B
ADDER_ROUND --(acc_rounded[47:0])--> ARITH_RSHIFT                     input

--- WIRES (Truncation + Saturation) ---
ARITH_RSHIFT --(acc_shifted[39:0] = acc_rounded[47:8])--> CMP_SAT_POS  input A
Constant +32767 --> CMP_SAT_POS                                        input B
ARITH_RSHIFT --(acc_shifted[39:0])--> CMP_SAT_NEG                     input A
Constant -32768 --> CMP_SAT_NEG                                        input B

ARITH_RSHIFT --(acc_shifted[15:0])--> MUX_SAT_NEG                     input 0 (normal)
Constant -32768 --> MUX_SAT_NEG                                        input 1 (saturate min)
CMP_SAT_NEG --(sat_neg)--> MUX_SAT_NEG                                select

MUX_SAT_NEG --(mux_neg_out)--> MUX_SAT_POS                            input 0 (normal)
Constant +32767 --> MUX_SAT_POS                                        input 1 (saturate max)
CMP_SAT_POS --(sat_pos)--> MUX_SAT_POS                                select

MUX_SAT_POS --(acc_trunc[15:0])--> [OUTPUT ke ACTIVATION UNITS]

--- WIRES (Feedback ke generator_top) ---
AXI4_MASTER_FSM --(c_out_cnt[11:0] = current_c_out)--> [EXT OUTPUT ke BIAS_MEM]

--- RINGKASAN HARDWARE ---
Total Adder       : 2 (acc + round)
Total MUX 2:1     : 3 (bias/acc select + sat_neg + sat_pos)
Total Comparator  : 2 (saturation)
Total D-FlipFlop  : 1 (acc_reg, 48-bit)
Total Shift       : 2 (left shift bias + right shift requant)


=============================================================================
DIAGRAM 4: PARALLEL ACTIVATION + OUTPUT MUX
=============================================================================
Arsitektur: 3 fungsi aktivasi jalan paralel, dipilih oleh MUX 4:1
Semua combinational (0 cycle latency)

--- NODES ---
NODE  REQUANT_SAT       : [EXT] Output dari Diagram 3. acc_trunc[15:0].
NODE  CONFIG_LUT        : [EXT] Dari generator_top. cur_act[1:0].

--- LEAKY RELU NODES (leaky_relu.v, u_lrelu) ---
NODE  LR_CMP            : Comparator. x_in >= 0.
NODE  LR_MULT           : Signed Multiplier. x_in × 51 (16b × 16b = 32b).
NODE  LR_ARSHIFT        : Arithmetic Right Shift. neg_prod >>> 8 (FRAC_W).
NODE  LR_MUX            : MUX 2:1. is_pos ? x_in : neg_val.

--- RELU NODES (relu.v, u_relu) ---
NODE  R_CMP             : Comparator. x_in >= 0.
NODE  R_MUX             : MUX 2:1. is_pos ? x_in : 0.

--- TANH NODES (tanh_act.v, u_tanh) ---
NODE  T_SIGN_CHECK      : Comparator. x_in[15] (sign bit check).
NODE  T_NEGATOR         : Negator. -x_in (2's complement).
NODE  T_ABS_MUX         : MUX 2:1. x_in[15] ? -x_in : x_in.
NODE  T_SEG_RSHIFT      : Right Shift. x_abs >> 5 (divide by seg_width=0.125).
NODE  T_SEG_CLAMP       : Comparator + MUX. seg >= 32 ? 31 : seg.
NODE  T_FRAC_EXTRACT    : Wire routing. frac = x_abs[4:0] (lower 5 bits).
NODE  T_LUT_LO          : LUT Read. lut[seg_idx] = lo.
NODE  T_LUT_HI          : LUT Read. lut[seg_idx + 1] = hi.
NODE  T_DIFF_SUB        : Subtractor. diff = hi - lo.
NODE  T_INTERP_MULT     : Multiplier. diff × frac.
NODE  T_INTERP_RSHIFT   : Right Shift. interp_full >> 5.
NODE  T_INTERP_ADD      : Adder. lo + interp_val.
NODE  T_SAT_MUX         : MUX 2:1. sat ? ONE(256) : interp_val.
NODE  T_SIGN_MUX        : MUX 2:1. x_in[15] ? -mag : mag.

--- FINAL MUX NODE ---
NODE  ACT_MUX_4TO1      : MUX 4:1. cur_act selects output.

--- WIRES (Leaky ReLU) ---
REQUANT_SAT --(acc_trunc = x_in[15:0])--> LR_CMP                     input
REQUANT_SAT --(acc_trunc = x_in[15:0])--> LR_MULT                    input A
Constant 51 (SLOPE ≈ 0.2×256) --> LR_MULT                             input B
LR_MULT --(neg_prod[31:0])--> LR_ARSHIFT                              input
LR_ARSHIFT --(neg_val[15:0])--> LR_MUX                                input 0 (negative path)
REQUANT_SAT --(x_in[15:0])--> LR_MUX                                  input 1 (positive path)
LR_CMP --(is_pos)--> LR_MUX                                           select
LR_MUX --(lrelu_out[15:0])--> ACT_MUX_4TO1                           input 0

--- WIRES (ReLU) ---
REQUANT_SAT --(acc_trunc = x_in[15:0])--> R_CMP                      input
REQUANT_SAT --(x_in[15:0])--> R_MUX                                   input 1 (positive path)
Constant 0 --> R_MUX                                                   input 0 (zero)
R_CMP --(is_pos)--> R_MUX                                             select
R_MUX --(relu_out[15:0])--> ACT_MUX_4TO1                             input 1

--- WIRES (Tanh) ---
REQUANT_SAT --(acc_trunc = x_in[15:0])--> T_SIGN_CHECK               input
REQUANT_SAT --(x_in[15:0])--> T_NEGATOR                               input
REQUANT_SAT --(x_in[15:0])--> T_ABS_MUX                               input 0 (positive)
T_NEGATOR --(-x_in[15:0])--> T_ABS_MUX                                input 1 (negated)
T_SIGN_CHECK --(sign_bit)--> T_ABS_MUX                                select

T_ABS_MUX --(x_abs[15:0])--> T_SEG_RSHIFT                             input
T_ABS_MUX --(x_abs[15:0])--> T_FRAC_EXTRACT                          input
T_SEG_RSHIFT --(seg_full[15:0])--> T_SEG_CLAMP                        input
T_SEG_CLAMP --(seg_idx[4:0])--> T_LUT_LO                              address
T_SEG_CLAMP --(seg_idx+1)--> T_LUT_HI                                 address
T_SEG_CLAMP --(sat)--> T_SAT_MUX                                      select

T_LUT_HI --(hi[15:0])--> T_DIFF_SUB                                   input A (minuend)
T_LUT_LO --(lo[15:0])--> T_DIFF_SUB                                   input B (subtrahend)
T_DIFF_SUB --(diff[15:0])--> T_INTERP_MULT                            input A
T_FRAC_EXTRACT --(frac[4:0])--> T_INTERP_MULT                        input B
T_INTERP_MULT --(interp_full[31:0])--> T_INTERP_RSHIFT                input
T_LUT_LO --(lo[15:0])--> T_INTERP_ADD                                 input A
T_INTERP_RSHIFT --(interp_val[15:0])--> T_INTERP_ADD                  input B
T_INTERP_ADD --(interp_result)--> T_SAT_MUX                           input 0 (normal)
Constant 256 (ONE = 1.0 in Q8.8) --> T_SAT_MUX                        input 1 (saturated)
T_SAT_MUX --(mag[15:0])--> T_SIGN_MUX                                 input 0 (positive)
T_NEGATOR style --(−mag)--> T_SIGN_MUX                                 input 1 (negated)
T_SIGN_CHECK --(sign_bit)--> T_SIGN_MUX                               select
T_SIGN_MUX --(tanh_out_w[15:0])--> ACT_MUX_4TO1                      input 2

--- WIRES (Bypass Path + Final MUX) ---
REQUANT_SAT --(acc_trunc[15:0])--> ACT_MUX_4TO1                      input 3 (bypass, no activation)
CONFIG_LUT --(cur_act[1:0])--> ACT_MUX_4TO1                           select (2-bit)
ACT_MUX_4TO1 --(final_pixel[15:0])--> [OUTPUT ke AXI WRITE → DDR]

--- CUR_ACT MAPPING ---
cur_act = 0 → lrelu_out  (Layer 0-4: Encoder, LeakyReLU)
cur_act = 1 → relu_out   (Layer 6-10: Decoder, ReLU)
cur_act = 2 → tanh_out_w (Layer 11: Output, Tanh)
cur_act = 3 → acc_trunc  (Layer 5: Bottleneck 1×1, No activation)

--- RINGKASAN HARDWARE ---
Leaky ReLU: 1 Multiplier + 1 Shift + 1 Comparator + 1 MUX
ReLU:       1 Comparator + 1 MUX
Tanh:       1 Negator + 2 LUT read + 1 Subtractor + 1 Multiplier + 1 Adder + 2 Shift + 3 MUX + 1 Comparator
Final MUX:  1 MUX 4:1
Total Multiplier  : 2 (LR + Tanh interp)
Total Adder       : 1 (Tanh interp)
